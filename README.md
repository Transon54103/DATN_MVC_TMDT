📚 BookMart - Website Bán Sách ASP.NET 8 MVC
🚀 Giới thiệu

BookMart là một dự án website thương mại điện tử bán sách được xây dựng bằng ASP.NET 8 MVC. 
Và được update và phát triển thêm về giao diện, kèm theo tính năng gợi ý sản phẩm từ phiên bản cũ do tôi học tập và tự xây dựng nên

🚀link repo git phiên bản cũ: https://github.com/Transon54103/ThuongMaiDT_MVC
🚀link online: https://tmdtmvc-gug7cvbagpekfygj.canadacentral-01.azurewebsites.net/


Dự án cung cấp đầy đủ các chức năng:

- Quản lý sản phẩm, giỏ hàng, đơn hàng, tài khoản.

- Tích hợp thuật toán Apriori để gợi ý sản phẩm dựa trên lịch sử mua hàng.

- Tích hợp Stripe để xử lý thanh toán trực tuyến an toàn và nhanh chóng.


🛠️ Công nghệ sử dụng

ASP.NET Core 8.0 MVC

Entity Framework Core 8 (Code-First)

SQL Server (lưu trữ dữ liệu)

Bootstrap 5 (UI/UX responsive)

Apriori Algorithm (gợi ý sản phẩm)

Stripe Payment Gateway (xử lý thanh toán)

⚙️ Tính năng chính
👤 Người dùng

Đăng ký / Đăng nhập tài khoản.

Duyệt, tìm kiếm, lọc sách theo danh mục / tác giả.

Thêm sản phẩm vào giỏ hàng, đặt hàng, thanh toán.

Xem lịch sử mua hàng.

Nhận gợi ý sản phẩm liên quan bằng Apriori.

Thanh toán trực tuyến qua Stripe (Credit/Debit Card).

🛒 Quản trị viên (Admin)

CRUD sản phẩm.

Quản lý người dùng, đơn hàng.

Xem báo cáo bán hàng, sản phẩm bán chạy.

🤖 Hệ thống gợi ý (Recommendation System)

Áp dụng Apriori cho Market Basket Analysis.

Tìm các luật kết hợp từ dữ liệu đơn hàng.

Hiển thị gợi ý sản phẩm khi người dùng mua hàng.

💳 Thanh toán Stripe

Stripe được tích hợp để xử lý thanh toán an toàn:

Người dùng có thể thanh toán trực tiếp bằng thẻ Visa/MasterCard.

Hỗ trợ xác thực 3D Secure.

Tích hợp qua thư viện Stripe.NET.
